# 題目｜礁溪尋寶：溫泉小鎮的祕密任務
> **一款以宜蘭礁溪為主題的 3D 文化尋寶遊戲**  
> 玩家扮演第一次來到礁溪的旅人，攜帶「礁溪文化尋寶護照」走訪三大景點、完成五項任務、收集五枚專屬印章，開啟文化寶箱領取「礁溪文化旅人」數位徽章！

---

## 🎮 遊戲核心特色與必做內容實作

1. **可探索的 3D 地圖**：
   - 完整呈現礁溪平原街道、溫泉水道、廟宇建築與雪山山脈山林地貌。
   - 支援全方位平滑移動、滑鼠右鍵/左鍵拖曳 360 度環繞旋轉視角、滾輪縮放距離。
   - 內建雷達小地圖與一鍵快速地標導航（迎賓任務板、湯圍溝、協天廟、五峰旗），便於評分與展示。
   - 支援行動裝置觸控虛擬搖桿。

2. **三個可辨識的景點**：
   - ♨️ **湯圍溝溫泉公園**：木造檜木足湯泡腳亭、下凹石砌水池、清澈溫泉水、冉冉升起的溫泉白煙蒸氣粒子、日式石燈籠與公園石碑。
   - 🏮 **礁溪協天廟**：宏偉中式紅柱牌樓、正殿閩南工藝**「雙翹燕尾脊」**屋頂、八根朱紅圓柱、廟埕大天公爐與祈福案桌。
   - 🏞️ **五峰旗風景區**：後方聳立五座並列的險峻尖峰（五峰旗由來）、垂直岩壁落差的三層飛瀑構造、奔騰水簾與水霧粒子、木造觀瀑亭「五峰亭」。

3. **真實實景照片素材**：
   - 收錄 11 張來自維基共享資源（Wikimedia Commons）創用 CC 授權與宜蘭文史考證的真實照片。
   - 涵蓋湯圍溝足湯、木造浴場、協天廟牌樓、大殿神案、五峰旗各層瀑布、礁溪特產蔬菜（溫泉空心菜、溫泉蔥、溫泉番茄）。

4. **五大可操作的文化線索與任務**：
   - **任務 1（湯圍溝）**：【美人湯湧泉之謎】—— 調查溫泉告示牌，辨識弱鹼性碳酸氫鈉泉水質特性。
   - **任務 2（湯圍溝）**：【溫泉特產蔬菜籃】—— 辨識利用溫泉水冬季恆溫抗寒灌溉的「礁溪溫泉空心菜」。
   - **任務 3（協天廟）**：【協天廟歷史與建築巡禮】—— 研讀石碑，探究清嘉慶九年（1804年）建廟歷史、燕尾脊建築與「壽龜祭」傳統。
   - **任務 4（協天廟）**：【心誠則靈民俗擲筊體驗】—— 拋擲 3D 筊杯，實測「一平一凸」聖筊寓意與敬天哲理。
   - **任務 5（五峰旗）**：【五峰飛瀑與地景拼圖】—— 觀摩山景明信片，解密五座尖峰地名由來與三層瀑布落差。

5. **每關操作與回饋機制**：
   - 點擊或走近按下 `[E]` 調查線索。
   - 閱讀線索後進行操作選擇；答錯時提供親切提示，可無限次重試。
   - 答對時播放慶祝音效、展示文化歷史解說卡，並蓋上專屬印章（同一關只計一枚印章，不重複累計）。

6. **文化護照、寶箱結局與重新遊玩**：
   - 按 `[P]` 鍵或點擊 HUD「文化護照」，開啟五格印章簿、實景手帳相簿與下一步智慧導航。
   - 集滿 5 枚印章後，中央迎賓廣場的「文化寶箱」綻放光芒，開箱噴發彩帶並頒發**「礁溪文化旅人」**數位榮譽徽章與結業證書。
   - 設有**「重新遊玩」**按鈕，點擊後印章與寶箱進度完整歸零（0 / 5），旅人傳送回起點，可重新體驗遊戲。

## 🚀 執行與開啟方式說明

### 方法 A：本機開發與預覽模式（最推薦）
電腦已安裝 Node.js 環境：
```bash
# 1. 進入專案目錄
cd jiaoxi-treasure-hunt

# 2. 啟動本機伺服器
npm run dev
# 或預覽打包成品：
npm run preview
```
開啟瀏覽器訪問控制台顯示的網址（例如 `http://localhost:5173/`）。

### 方法 B：直接使用編譯後的成品檔（dist 目錄）
專案的 `dist/` 資料夾為已打包完成的純靜態網頁（已將 CSS 與 JS 模組化打包，且支援相對路徑）：
- 可以使用任意靜態伺服器開啟（例如 VS Code Live Server、Python `python -m http.server`）。
- 或將 `dist` 資料夾直接部署至 GitHub Pages、Vercel 或 Netlify，即可產生線上直接遊玩網址。

## ⌨️ 基本操作指南

| 動作 | 鍵盤 / 滑鼠操作 | 行動裝置操作 |
| :--- | :--- | :--- |
| **移動角色** | `W` `A` `S` `D` 或 `方向鍵` | 左下角虛擬搖桿 |
| **旋轉鏡頭** | 滑鼠左鍵/右鍵拖曳畫面 | 滑動畫面旋轉視野 |
| **縮放視野** | 滑鼠滾輪滑動 | 雙指縮放 |

| **開啟文化護照** | 按 `P` 鍵，或點擊右上角「文化護照」按鈕 | 點擊頂部「文化護照」按鈕 |
| **快速傳送** | 點擊右上角地標按鈕（任務板 / 湯圍溝 / 協天廟 / 五峰旗） | 點擊頂部快捷按鈕 |
| **音效切換** | 點擊「🔊 音效」按鈕切換靜音 | 點擊「🔊 音效」按鈕 |
